Clearer source selection, visible firmware progress, and more ways to drive your gauges.

- Firmware download, writing, verification and restart status now stays below the PCB sketch. Downloads and writes show measured progress; connection and verification stages show activity and elapsed time. Completion requires checking the restarted board’s firmware version.
- Larger PWM headings make the selected output easy to spot.
- New Pulse app icon and matching branding throughout the interface.
- Choose from This computer, ESP32 board, AI tools or Prices, with search across all categories.
- New GPU usage, CPU/GPU temperature, **System volume** (your volume setting), and separate **Audio level** (live playback) sources. Battery only appears when present.
- Select a drive, network interface, graphics processor or temperature sensor for each gauge.
- Track an individual Super Tracker product, optionally locked to one store. Basket coverage has been removed. Missing selected-store prices never fall back to another shop.
- Linear, exponential and logarithmic output scales, with a matching dial preview. Curved scales need the included firmware 2.3.0.
- Windows setup detects an existing USB driver. Install or repair it from Connect board, with a layout that fits smaller Windows work areas.

Existing users can update through Settings → Updates. Update both the app and board firmware for curved scales. Gauge assignments and calibration are preserved.

macOS now requires 14.6 or newer for native playback metering. Audio level asks for system audio access; no audio is saved or uploaded. Duplex macOS audio devices are left unavailable to prevent microphone capture. Linux playback metering needs PulseAudio or PipeWire’s PulseAudio service. Hardware sensor support varies: Windows CPU temperatures and additional GPU sensors require Libre Hardware Monitor running; NVIDIA GPU temperature can use its driver directly. Missing readings appear as a dash.

Super Tracker’s production hostname was not resolving during release verification. Product/store selection and parsing were verified against its API definition and controlled fixtures; live prices remain unavailable until that service is reachable. National prices are the lowest current shelf price across retailers’ national medians, in NZ dollars. Store locking uses the exact shop. Club and multibuy promotions are excluded.

The `.sig`, `.json`, `.bin`, and `.app.tar.gz` files support automatic updates and firmware installation. Linux in-app updates require the AppImage. ESP Gauge verifies update signatures; publisher signing and macOS notarization remain unconfigured.
