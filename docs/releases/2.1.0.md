A first public test release of the native six-channel gauge monitor.

- Calibrate both ends of a gauge across the full 0–100% PWM range. Existing full-scale settings are retained, with a zero lower endpoint.
- Port labels and traces recede when USB disconnects; the dimmed PCB stays centred.
- Embedded macOS title bar with native window controls.
- Install or update firmware from Settings → Updates. The native ESP32 flasher checks the chip, verifies signed release metadata and binary checksums, and preserves the configuration partition.
- Automatic release checks and signed app updates from the same GitHub release.
- Firmware split into configuration, output engine, serial protocol, sensing and indicator modules.

Packages include Apple Silicon and Intel macOS, Windows x64 and Linux x64. Linux in-app updates use the AppImage; deb/RPM installations should be updated with the matching package. Platform publisher signing and macOS notarization are not configured; update signatures are separate and are verified by ESP Gauge.

The board has no electrical or needle feedback. Calibrate against the physical gauge using the resistor chosen for your instrument. All outputs support 0–100% duty; absent readings and paused gauges rest at zero output.
