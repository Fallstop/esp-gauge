Physical gauges for your AI work, and standalone waveform generators.

- Discover Codex, Claude Code and OpenCode automatically. Choose working agents, CLI sessions, memory, tokens or the subscription quota windows actually available for the installed provider.
- Pair with a running local codeslop / T3 Code server for working agents, tasks needing attention, completed turns, tool calls and context-window usage.
- Sine, triangle, sawtooth and square-wave sources run on the ESP32 without the PC. Adjust their period and phase directly.
- Super Tracker food-price index, monthly/yearly movement and coverage, using the production supertracker.nz public API. Sources become available when that upcoming endpoint is live.
- Raw-value ranges support nonzero and negative starting points. Existing electrical calibration remains unchanged.
- Edits are held during installation, preventing changes from racing an app restart or firmware flash.
- Linux AppImages use a checksum-pinned compatible runtime and gzip compression, including support for existing AppImageLauncher 2 installations.

Update both the app and firmware through Settings → Updates to use waveforms. Existing settings are preserved.
