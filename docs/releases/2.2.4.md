Easier Windows setup, with the CH340C USB driver included. Downloads now show the operating system in the filename.

| Your computer | Download |
| --- | --- |
| Windows 10 / 11 (x64) | [Windows installer](https://github.com/Fallstop/esp-gauge/releases/download/v2.2.4/ESP-Gauge-2.2.4-Windows-x64-Setup.exe) |
| macOS (Apple Silicon: M1 or newer) | [macOS disk image](https://github.com/Fallstop/esp-gauge/releases/download/v2.2.4/ESP-Gauge-2.2.4-macOS-Apple-Silicon.dmg) |
| Linux (x64) | [Linux AppImage](https://github.com/Fallstop/esp-gauge/releases/download/v2.2.4/ESP-Gauge-2.2.4-Linux-x64.AppImage) |

On Windows, accept the USB driver setup offer, approve the administrator prompt, and choose **INSTALL** in the WCH window. The driver is included, so no separate download is needed. If your board already connects, you can skip this step. **ESP Gauge USB driver setup** in the Start menu lets you retry later. WebView2 is downloaded if needed.

Existing users can update through **Settings → Updates**. App updates skip the driver prompt. Your gauge assignments and calibration are preserved; firmware has the matching version with unchanged behaviour.

For other installation methods: [Linux Debian/Ubuntu package](https://github.com/Fallstop/esp-gauge/releases/download/v2.2.4/ESP-Gauge-2.2.4-Linux-x64.deb), [Linux RPM package](https://github.com/Fallstop/esp-gauge/releases/download/v2.2.4/ESP-Gauge-2.2.4-Linux-x64.rpm), and [Windows MSI for administrators](https://github.com/Fallstop/esp-gauge/releases/download/v2.2.4/ESP-Gauge-2.2.4-Windows-x64.msi). MSI and unattended installations require running the bundled driver separately. Linux in-app updates require the AppImage.

The `.sig`, `.app.tar.gz`, `.json`, and `.bin` assets support automatic updates and firmware installation. Use the downloads in the table for normal installation. This release's Mac build is for Apple Silicon.

ESP Gauge verifies update signatures. WCH's bundled driver retains its vendor signature; ESP Gauge publisher signing and macOS notarization are not configured.
