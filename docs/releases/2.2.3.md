More precise header selection and a refined board interface.

- Click the actual silhouette of any PWM header. Selection, hover and keyboard focus follow the supplied connector outlines, including shared edges.
- Leader traces clear neighbouring connectors, making each label's physical output easier to follow.
- The Add a gauge view uses the custom header drawing, with graphite faces, a dark recess and pale metal contacts.

Existing gauge assignments and calibration are preserved. Firmware is included with the matching version; its behaviour is unchanged from 2.2.2.

Install through Settings → Updates, or download a package for Apple Silicon or Intel macOS, Windows x64, or Linux x64. Linux in-app updates use the AppImage. Update signatures are verified by ESP Gauge; publisher signing and macOS notarization are not configured.
